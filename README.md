One word for the boss: **Ghost**.

The boss who is never there, never replies, and only appears when something has gone wrong. One word, five letters, no caption needed — the joke lands on its own, rings true in any workplace, and is fresher than the first word anyone reaches for.

## Run it

```sh
python3 main.py
```

Writes the single word to `/output/entry.txt` (UTF-8, 1–30 characters, a single word with no spaces). Standard library only — no dependencies.
